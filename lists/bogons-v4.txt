# Abuse Defender - category "bogons" (IPv4)
# Destinations that must never be reached over the public uplink. Traffic to them is
# what hosting providers report as "netscan"/"private network scan" abuse.
# Source: IANA IPv4 Special-Purpose Address Registry (RFC 6890 and updates)
#   https://www.iana.org/assignments/iana-ipv4-special-registry/
# and IANA IPv4 Address Space Registry (240/4 "Reserved - Future use")
#   https://www.iana.org/assignments/ipv4-address-space/
# Format: one CIDR per line, '#' comments allowed. Validated by tools/build-lists.sh.
#
# Deliberately NOT listed (see lists/SOURCES.md):
#   127.0.0.0/8      loopback - never leaves the host; Abuse Defender never filters "lo"
#   192.31.196.0/24, 192.52.193.0/24, 192.175.48.0/24  globally reachable (AS112, AMT)
#
